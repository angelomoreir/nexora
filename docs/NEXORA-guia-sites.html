1. O que são Sites

Um Site no NEXORA é um portal interno — o equivalente a um site do SharePoint. Serve para agregar e apresentar conteúdo de toda a plataforma num sítio temático: páginas compostas por blocos («widgets») que puxam dados vivos de documentos, listas e notícias.

A ideia central: Documentos, Listas e Notícias são os dados; os Sites são a apresentação organizada desses dados para uma audiência — a «homepage» de um departamento, projeto ou equipa, em vez de cada pessoa andar a procurar conteúdo espalhado.

2. Anatomia de um site

ElementoO que é

PáginaUma página dentro do site, composta por widgets ordenados; tem slug próprio e estado Rascunho/Publicada
Página inicialA página marcada isHome — o que se vê no separador «Início»
WidgetUm bloco de conteúdo na página (ver §4)

3.1 Tipos de site

3.2 Visibilidade

Privado (PRIVATE)Só os membros do site — não aparece na lista dos outros

3.3 Papéis de site (locais)

Cada site tem a sua própria gestão de membros — independente do papel global na organização. Um Member da organização pode ser Administrador deste site.

Papel localCapacidade no site
AdministradorTudo: definições, membros, páginas, eliminar o site
GestorGerir páginas e membros
EditorCriar e editar páginas
ContribuidorContribui conteúdo dentro dos limites definidos
LeitorSó consulta

5. Criar e construir — passo a passo

5.1 Criar o site

  1. Sites → «Novo site».
  2. Preencher: nome, descrição, tipo (Departamento/Projeto/Equipa/Hub), visibilidade, ícone e cor.
  3. Opcional: escolher um site pai para criar um sub-site.
  4. Site criado — o criador fica como Administrador do site.

5.2 Construir páginas

  1. Dentro do site → separador «Conteúdo» → criar página (nasce com um widget Hero).
  2. Editar a página: adicionar/ordenar widgets, configurar cada um (título do hero, lista a mostrar, URL do link…).
  3. Definir o slug (URL amigável) e mudar o estado para Publicada.
  4. Marcar «página inicial» para que apareça no separador «Início» do site.

5.3 Gerir membros

  1. Separador «Membros» → adicionar membros da organização com o papel local adequado.
  2. Para sites privados, esta lista é quem controla o acesso — quem não está aqui nem vê o site.

5.4 Definições e zona de perigo

  1. Separador «Definições» (só gestores): renomear, mudar visibilidade, cor/ícone.
  2. Zona de perigo → eliminar o site (confirmação obrigatória; remove páginas e associações).

6. Exemplos práticos

Exemplo 1 — Portal de RH (Departamento, Organização)
  • Hero: «Recursos Humanos — tudo o que precisa num só lugar»
  • Notícias: últimas notícias associadas ao site de RH
  • Lista: «Benefícios» (lista NEXORA)
  • Link: «Pedir férias» → aponta para o formulário interno
  • Documentos recentes: políticas e procedimentos atualizados
Exemplo 2 — Projeto confidencial (Projeto, Privado)

Site privado «Projeto Alfa»: só os 5 membros da equipa o veem. Página inicial com Hero + KPI do progresso + lista «Tarefas do projeto». A membresia do site controla quem entra — um Admin da organização sem ser membro do site privado não o vê na lista.

Exemplo 3 — Intranet com hierarquia (Hub)

Site «Intranet» (Hub, Organização) como entrada geral, com sub-sites «RH», «Comercial» e «Operações» pendurados — cada departamento gere o seu sub-site com os seus membros e páginas.

Dupla camada: a permissão global (sites.manage) controla quem pode criar sites; os papéis locais controlam o que cada membro faz dentro de cada site. Um Member global pode ser Administrador de um site privado.

8. Boas práticas e resolução de problemas

  • Pense na audiência: quem vai usar este site e o que procura? Organize a página inicial por essa lógica.
  • Prefira widgets dinâmicos (documentos recentes, notícias, listas) a texto estático — a página mantém-se atualizada sozinha.
  • Sites privados precisam de membros: criar um site privado sem adicionar membros deixa-o invisível para todos exceto o criador.
  • Associe as notícias ao site — o widget «Notícias» de um site mostra as notícias ligadas a ele.
  • Publicar ≠ visível sem página inicial: um site sem página inicial publicada mostra «Início» vazio.
