# Sequências de prospeção

> Personalizar **sempre** a primeira linha (projeto recente, certificação, notícia, vaga aberta). Mensagens genéricas têm taxa de resposta perto de zero.
> Campos: `{nome}`, `{empresa}`, `{gancho}` (facto concreto sobre a empresa), `{n}` (n.º de pessoas), `{link_demo}` (calendário), `{assinatura}`.
> RGPD: prospeção B2B por email para endereços profissionais com base em interesse legítimo — incluir sempre forma simples de recusar e respeitar de imediato.
>
> **Claims técnicas verificadas no código** (não prometer mais do que isto):
> - Formulário submetido → workflow (`form.submitted`) com os valores do formulário no contexto, por id e por label do campo (`submission.<campo>`); condição suporta `=`, `!=`, `>`, `>=`, `<`, `<=`, existe/não existe → pode criar tarefa/notificar. Coberto por teste automático.
> - Aprovações funcionam no telemóvel (UI web responsiva — não há app nativa).
> - Links de partilha de documentos/pastas com password e data de expiração, permissões leitura/edição/pedido de ficheiros.
