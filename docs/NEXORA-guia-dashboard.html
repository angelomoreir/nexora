1. O que é o Dashboard

O Dashboard é o painel de controlo da organização — métricas, atividade e atalhos num único ecrã. Mostra como está a operação: tarefas, documentos, processos, aprovações e atividade recente, com suporte a múltiplos dashboards personalizados que pode criar, nomear e alternar.

2. O que a página contém

ElementoDescrição
Checklist de onboardingPara organizações novas — passos sugeridos para começar (criar conteúdo, convidar membros…)
Recomendação inteligenteSugestão contextual gerada a partir do estado atual da organização
KPIs / widgetsCartões de métrica (tarefas, documentos, workflows, aprovações pendentes, notificações não lidas)
ComunicadosAnúncios administrativos da organização (criados em Administração → Comunicados)
Aprovações pessoaisAs suas aprovações pendentes — atalho direto
Seletor de dashboardAlterna entre o dashboard por defeito e dashboards personalizados (a escolha fica memorizada)

3. Dashboards personalizados

  1. Criar: «Novo dashboard» → dar nome → nasce como dashboard adicional.
  2. Renomear/gerir dashboards existentes no seletor do topo.
  3. Cada dashboard é uma composição de widgets — a configuração é renderizada pela API (/dashboards/:id/render).
  4. Alternar entre «Dashboard» (por defeito) e os personalizados no seletor — a preferência fica gravada no browser.
Caso de uso: um dashboard «Operações» com KPIs de tarefas e workflows, e outro «Conteúdo» com documentos e notícias — cada equipa tem o seu painel.

4. Exemplos práticos

Exemplo 1 — Reunião de equipa

Abrir o Dashboard no início da reunião semanal: quantas tarefas em curso, quantas aprovações paradas, o que foi criado esta semana — contexto imediato para a discussão.

Exemplo 2 — Onboarding de nova organização

Organização recém-criada: o checklist guia os primeiros passos (convidar membros, criar primeiro documento/lista) e desaparece quando a organização ganha vida.

Exemplo 3 — Comunicado visível

O Admin publica «Sistema em manutenção sexta 18h» em Administração → Comunicados — aparece no Dashboard de todos os membros.

6. Dashboard vs O meu dia vs Análise

PáginaResponde aCaráter
O meu dia«O que tenho de fazer hoje?»Pessoal, acionável
Dashboard«Como está a operação agora?»Organização, visão geral
Análise«Como evoluímos no tempo?»Tendências e gráficos
  • Os dados do Dashboard refletem a organização ativa — mude de organização no seletor do topo para ver outro tenant.
  • Se os cartões aparecerem vazios numa organização nova, é normal — precisam de atividade para mostrar dados.
