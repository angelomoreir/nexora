1. O que é a Administração

A Administração é o centro de gestão da organização — utilizadores, equipas, papéis, auditoria, segurança, integrações e definições. O menu lateral só a mostra a quem tem pelo menos uma permissão administrativa, e o painel apresenta só os cartões que o utilizador pode abrir — cada cartão está ligado à sua permissão.

4. Funções (papéis)

  • Sistema: Super Admin, Admin, Manager, Editor, Member, Viewer — não editáveis nem elimináveis (a API recusa).
  • Personalizadas: o Admin cria funções com conjuntos próprios de permissões — ex.: «Contabilidade» com documents.edit + lists.manage.
  • Eliminar função personalizada: só se nenhum membro a estiver a usar.

5. Auditoria

Registo imutável de eventos: criação/edição/remoção de utilizadores, papéis, documentos, processos, logins administrativos — com ator, ação, recurso e timestamp. Essencial para responder «quem mudou isto?» e para conformidade.

6. Exemplos práticos

Exemplo 1 — Entrada de um novo colaborador

Administração → Utilizadores → «Convidar utilizador» (ou criar diretamente) → escolher papel → o novo membro entra com as permissões certas desde o primeiro login.

Exemplo 2 — Integração com sistema externo

Administração → Webhooks → criar endpoint https://erp.exemplo.pt/hook → eventos da plataforma (tarefa criada, workflow concluído…) são enviados para lá.

Exemplo 3 — Anúncio a todos

Administração → Comunicados → «Manutenção sexta 18h» → aparece no Dashboard de todos os membros.

Exemplo 4 — Investigar uma alteração

«Quem suspendeu a conta do João?» → Administração → Auditoria → filtrar por ação user.updated → ator e timestamp.

7. Boas práticas e resolução de problemas

  • Mínimo privilégio: atribua o papel mais baixo que cubra a função — Viewer/Member por defeito.
  • Prefira convites: o utilizador define a própria password em vez de a receber criada.
  • Funções personalizadas para equipas reais: quando 3+ pessoas partilham o mesmo perfil de acesso, crie uma função.
  • Auditoria regular: reveja ações sensíveis (suspensões, mudanças de papel) periodicamente.
